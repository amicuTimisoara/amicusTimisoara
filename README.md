# amicus-api

Backend API for AMiCUS Timișoara, shared by the mobile and web clients.

## Repos

| Repo | Role |
|---|---|
| `amicus-api` | this one — the backend |
| `amicus-mobile` | mobile client (not created yet) |
| `amicus-web` | web client (not created yet) |

## Contributing

`main` is protected: open a PR, get one approval, merge with **squash** (the only
merge method enabled). Merged branches are deleted automatically.
